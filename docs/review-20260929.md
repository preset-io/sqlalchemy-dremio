# Dremio 26.0.5 review regression replay

Release version: **3.0.5.1**. Reviewed baseline: `1147ce753a4d`.

## Fixes

- Parenthesize negative integer binds, so `100-:n` cannot turn into a `--`
  comment and discard a following tenant predicate.
- Render finite Decimal binds as `CAST('<exact text>' AS DECIMAL(p,s))`.
  Derive precision and scale from the Decimal tuple without rounding through
  the Python decimal context. This handles signed zero and 19–38 digit values.
  Values requiring precision or scale above 38 (including `1E-40`) raise
  `ProgrammingError` before transport rather than being silently rounded.
  Dremio's [DECIMAL limit is 38 digits](https://docs.dremio.com/current/reference/sql/data-types/).
- Match schema/table names case-insensitively in catalog reflection, including
  nested schema paths, `has_table`, table/view listing and autoload. Keep exact
  DECIMAL metadata and escaped string literals.
- Remove the contradictory Python 3.7 classifier; minimum Python is 3.8.

## Reproduction

One disposable container, loopback-only, started while host load was below 80:

```sh
docker run -d --name last5-dremio-0929 --cpus 4 --memory 8g \
  -e DREMIO_MAX_HEAP_MEMORY_SIZE_MB=2048 \
  -e DREMIO_MAX_DIRECT_MEMORY_SIZE_MB=2048 \
  -p 127.0.0.1:29047:9047 -p 127.0.0.1:32119:32010 \
  dremio/dremio-oss@sha256:b030b5dbffe2c789de51543763551c6b1fb6737c1030172a3a2d3b83c031588a
```

The image contains `dremio-accelerator-api-26.0.5-202509091642240013-f5051a07.jar`.
After `/apiv2/server_status` reports `OK`, bootstrap a disposable local user via
`PUT /apiv2/bootstrap/firstuser`, log in with `POST /apiv2/login`, and use
`POST /api/v3/catalog` to create `{"entityType":"space","name":"Review"}`
and `{"entityType":"folder","path":["Review","Sub"]}`. Set
`DREMIO_REVIEW_URL` to the local user's Flight URL (port 32119,
`?UseEncryption=false`). These are test-only credentials, not a remote account.

```sh
python -m pytest -q -W error::DeprecationWarning \
  test/test_sqlalchemy2.py test/test_additional.py \
  test/test_flight_dialect.py test/test_publish_wheel.py
python -m pytest -q -W error::DeprecationWarning test/test_review_live.py
# Run from an exported baseline checkout with the same new tests for controls:
PYTHONPATH="$BASELINE" python -m pytest -q test/test_sqlalchemy2.py -k review_
PYTHONPATH="$BASELINE" python -m pytest -q test/test_review_live.py
# Teardown only the container created for this replay:
docker rm -f last5-dremio-0929
```

The live suite creates/drops only `Review.Sub.Mixed`. It exercises the exact
review query with both literal and bound tenants, positive/negative integers,
negative Decimal and signed zero, and negative floats; exact 29/38-digit and
small/exponent Decimal round trips; explicit out-of-range refusal; and
mixed-case nested-schema autoload, decimal metadata, view/table separation,
and missing-table errors. No mock transport is used by this suite.

## Results (2026-09-29)

| Environment | Server-free suite | Live review suite |
| --- | ---: | ---: |
| Python 3.11.15 / SQLAlchemy 2.0.52 / pyarrow 25.0.1 | 87 passed | 22 passed |
| Python 3.11.15 / SQLAlchemy 1.4.54 / pyarrow 17.0.0 | 87 passed | 22 passed |
| Python 3.14.7 / SQLAlchemy 2.0.52 / pyarrow 25.0.1 | 87 passed | 22 passed |

Final Python 3.11 suites run with DeprecationWarnings promoted to errors; the
1.4 live harness uses `future=True` to avoid legacy implicit-DDL-autocommit
warnings. The first 1.4 replay exposed that harness warning (21 passed / 1
failed); the final run uses the corrected cross-version harness.

Against reviewed `1147ce753a4d`, the 23 new server-free checks produce **21
failures / 2 passes** (nonfinite Decimal rejection was already implemented).
The live control produces **15 failures / 7 passes**, including all eight
negative int/Decimal/signed-zero tenant cases returning `[(1, 'x'), (20, 'y')]`
instead of `[(1, 'x')]`. After the fixes every tenant case returns only `x`,
and `SELECT 1-:n` also has the expected arithmetic result. The 29-digit and
38-digit Decimal round trips are exact; `1E-40` is explicitly refused, not
converted to zero. The remaining live control failures cover large/exponent
Decimals, out-of-range error handling and case-insensitive reflection.

This replay does not re-claim the earlier TLS/Superset qualification as fresh
coverage at the new head. That broader 18-check run belongs to the reviewed
baseline. The downstream superset-shell#5276 wheel pin must be refreshed to
consume these changes after publication.
